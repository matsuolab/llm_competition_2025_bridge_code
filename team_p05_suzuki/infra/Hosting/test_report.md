## 🔧 環境設定

### リソース構成
- **ノード**: osk-gpu65 (メイン), osk-gpu63/64 (補助)
- **CPU**: 240コア
- **GPU**: 8 x NVIDIA GPU
- **メモリ**: 1TB+
- **時間制限**: 6時間

### 環境変数設定
```bash
TRANSFORMERS_NO_TORCHVISION=1
VLLM_WORKER_MULTIPROC_METHOD=fork
ulimit -v unlimited
```

## ❌ 失敗要因分析

### 主な問題点
1. **モデル互換性問題**
   - Qwen3-4BカスタムモデルとvLLMの互換性
   - モデル形式の不整合

2. **メモリ/GPU リソース問題**
   - モデルロード時のメモリ不足
   - GPU VRAM使用量の最適化不足

3. **設定パラメータ問題**
   - vLLMサーバー起動パラメータの調整不足
   - カスタムモデル特有の設定要件

4. **依存関係問題**
   - Pythonパッケージバージョン競合
   - CUDA/PyTorchバージョン不整合
