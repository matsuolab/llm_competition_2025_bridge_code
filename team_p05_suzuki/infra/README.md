# infra ディレクトリ ユーティリティ群

このディレクトリは、HPC環境における開発作業を効率化・自動化するための、各種スクリプトやプロジェクトを管理します。

## 概要

本ディレクトリには、大きく分けて以下の2種類のツールが含まれています。

1.  **汎用スクリプト**: 特定のプロジェクトに依存せず、単体で利用できる便利なスクリプト群です。
2.  **プロジェクト**: 特定の目的（例: LLM開発環境構築）のための、まとまったスクリプト群です。

---

## 汎用スクリプト

### 1. `create_env.sh`

* **役割:** 対話的に利用するための、汎用的なConda環境を新規に作成します。
* **特徴:** 環境名とPythonバージョンを引数で指定できます。`activate.d`の仕組みを使い、環境有効化時に必要な設定（`LD_LIBRARY_PATH`等）を自動で行います。
* **使用法:**
   `source` コマンドでの実行を**推奨**しますが、直接実行も可能です。
   ```bash
   # 使い方: source create_env.sh <環境名> [Pythonバージョン]
   #         または
   #         bash create_env.sh <環境名> [Pythonバージョン]
   
   # 推奨: sourceモードで実行（環境の自動アクティベート機能あり）
   source ~/team_suzuki/infra/create_env.sh my_env 3.10
   
   # 直接実行も可能（環境作成のみ、手動でアクティベートが必要）
   bash ~/team_suzuki/infra/create_env.sh my_env 3.10
   ```
   
   **注意:** `source` モードで実行した場合は、作成した環境を即座にアクティベートするオプションが提供されます。直接実行の場合は、環境作成後に手動で `conda activate` する必要があります。

### 2. `auto_cancel.sh`

* **役割:** Slurmクラスタ上の指定したノードで実行中の、**指定したユーザー名のジョブ**を一括で安全にキャンセルします。
* **特徴:** 複数のノードを引数として指定可能です。内部で`squeue`コマンドを実行し、対象のジョブIDを自動で取得してキャンセル処理を行います。
* **使用法:**
   実行権限を付与してスクリプトを実行します。
   ```bash
   # 使い方: ./auto_cancel.sh <ノード名1> [ノード名2] ...
   
   # 例: gpu001とgpu002で実行中の指定したユーザー名のジョブをすべてキャンセル
   ./auto_cancel.sh gpu001 gpu002
   ```

## プロジェクト

### `HPC/`

* **役割:** Slurmクラスタ上で、再現性の高いLLM向けGPU開発環境を自動で構築するためのプロジェクトです。
* **特徴:** PyTorchやCUDAツールキットのインストール、ApexやFlashAttentionといったライブラリのソースからのビルドまでを自動化します。
* **詳細:**
   具体的なセットアップ方法や使い方については、`HPC`ディレクトリ内のREADMEを参照してください。
   
   **-> `HPC/README.md`**
